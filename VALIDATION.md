# OrbitApply 0.17.0 validation

Run date: 2026-09-23. Environment: Linux, Python 3.12.14, Streamlit 1.63.0,
Pydantic 2.13.5. The preinstalled test dependencies were provided through
PYTHONPATH; they are not part of the release archive.

## Automated results

`python -m unittest discover -s tests -q`: **148 tests passed** in 8.797 seconds.
This includes the existing 132 tests, 15 new compression tests and one new
Streamlit usage-panel test. The existing job-folder test was also extended to
verify the saved usage report matches the result shown to the UI.

Covered behaviors include protected source strings, schema constraints, nested
data called `title`, Unicode and large integer preservation, optimizer bypass,
disable mode, invalid outputs, output-limit rejection, partial/absent metrics,
transport failures, cache-hit accounting, per-job file creation, state-preserving
navigation, serial generation, cancellation, sponsorship and application history.
Shell syntax checks cover the Mac launchers. Streamlit checks use AppTest.

These tests use mock model/network responses and synthetic resumes. They do not
establish live-model factual quality, real job-board accessibility, native Finder
or Windows behavior, Telegram delivery, or installation on clean Mac/Windows hosts.
The GitHub CI matrix is configured but has not run in GitHub yet.

## Offline payload measurement

See `benchmarks/RESULTS.json`, generated by `python benchmarks/measure_payload.py`.
Four synthetic fixtures compare the same messages and compact schema before and
after removing redundant generated labels. Each uses 200 local preparations.

| Request type | Payload characters removed | Reduction | Median preparation |
| --- | ---: | ---: | ---: |
| Evidence decision | 85 | 7.44% | 0.0268 ms |
| Bullet draft | 36 | 4.30% | 0.0158 ms |
| Claim audit | 200 | 13.21% | 0.0398 ms |
| Requirement extraction | 103 | 9.70% | 0.0370 ms |

These are character reductions and CPU timings on this environment, not measured
Ollama token savings or Mac/RTX inference speedups. Larger source fragments reduce
the percentage benefit. The compressor makes no extra model calls. The many
existing evidence and audit calls can still dominate tailoring time.

## Delivery scope

App rebrand, built-in schema/JSON compaction, local diagnostics, regression tests,
GitHub workflow and docs are included. The external AI Agent Content Compress
plugin was not available, so its integration is not claimed. No repository was
published, no license was selected for the owner's code, and no model or runtime
dependency was added. Existing review/factual-validation outcomes are unchanged.
